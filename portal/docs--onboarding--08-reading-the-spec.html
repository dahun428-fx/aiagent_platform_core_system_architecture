잘못된 해석

"MUST가 표기되어 있으므로 특정 제품을 사용해야 한다."

올바른 해석

"프로덕션 Agent 호출은 반드시 인증해야 한다(MUST)"는 요구사항이 있어도 IdP 제품은 TBD일 수 있습니다. MUST는 충족해야 할 요구사항이며, 제품 선택을 의미하지 않습니다.

FAQ

Agent를 플랫폼에 등록하려면 소스를 업로드해야 합니까?

업로드하지 않습니다. 소스는 팀 저장소에서 관리하며, Registry에는 불변 revision, artifact digest, Manifest, 평가 결과를 등록합니다.

LangGraph를 사용 중인 경우 프레임워크를 변경해야 합니까?

변경하지 않습니다. 공통 Runtime 계약과 framework adapter로 연결하며, Manifest의 runtime.framework와 runtime.adapter에 선언합니다.

외부 모델 API를 Agent 코드에서 직접 호출할 수 있습니까?

프로덕션 환경에서는 특정 공급사에 직접 결합하지 않고 Agent Gateway 모델 경로를 경유해야 합니다. 이를 통해 데이터 분류에 따른 외부 전송 통제와 공급사 교체 시 코드 변경 최소화가 가능합니다. 개발 단계부터 모델 경로 계약을 기준으로 구현하면 승격 시 변경 범위가 줄어듭니다.

Agent가 MCP 서버에 직접 연결할 수 있습니까?

기본 패턴은 Agent Gateway 도구 경로의 adapter가 MCP client를 소유하는 enterprise proxy 방식입니다. adapter는 OAuth 2.1 client로서 RFC 8707 resource indicator와 RFC 9728 Protected Resource Metadata를 사용합니다. MCP는 도구 프로토콜이며 회사 인가 정책을 대체하지 않습니다. tools/list는 허용된 도구만 노출하고, tools/call도 동일한 인가·입출력 검증·감사 규칙을 따릅니다.

도구 접근용 API 키는 어디에 저장합니까?

Agent 코드, Manifest, 환경 변수에 저장하지 않습니다. Credential Broker가 호출마다 단기 자격증명을 발급하며, 자격증명은 Agent Gateway 도구 경로의 adapter 내부에서만 사용됩니다.

등록한 Mac mini를 바로 서비스에 사용할 수 있습니까?

사용할 수 없습니다. 등록(registered)과 프로덕션 승인(production-approved)은 다르며, 프로덕션 환경에는 보안 검토, 평가 결과, 복구 검증, 위험도별 SLO 근거가 필요합니다.

예제의 TTL, 포트 등 수치를 그대로 사용할 수 있습니까?

사용할 수 없습니다. 예제의 주소, TTL, 호출 깊이, 평가 점수는 합성 값입니다. 회사 기준 수치는 TBD 등록부에서 결정합니다.

이 패키지로 프로덕션 환경을 바로 운영할 수 있습니까?

운영할 수 없습니다. 이 패키지는 구현 착수를 위한 기술 표준이며, 회사 IdP, 정책 엔진, 시크릿 관리, 실행 환경 연동과 운영 검증이 필요합니다. 착수 절차는 CI 통합을 참고하십시오.
