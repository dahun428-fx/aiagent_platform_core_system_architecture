주요 용어 정의

개발자 가이드에서 사용하는 용어의 권장 표기와 정의입니다. 규범적 정의는 용어와 규범이 기준입니다.

표기 원칙

  • Agent, Agent Gateway, Model Gateway, Credential Broker, Manifest 등 공식 명칭은 영문을 유지합니다.
  • 일반 기술 개념은 한국어를 사용하고, 최초 등장 시 영문을 병기합니다. 예: 멱등성(Idempotency), 신뢰 경계(Trust Boundary).
  • 설명문에서는 '프로덕션 환경', '프로덕션 승인'으로 표기하고, 코드·상태값(production, production-approved)은 원문을 유지합니다.
  • 각 장 상단의 주요 용어 링크를 선택하면 이 문서의 해당 항목으로 이동합니다.

예: 재무 사업부, 인사 사업부 · 신뢰 경계와 보안 통제

아키텍처

등록된 환경이라도 프로덕션 승인과는 별개입니다 · 플랫폼 아키텍처와 주요 구성요소

Agent Runtime Runtime

Registry Registry

상태: registered, eligible, production-approved, quarantined · Agent 수명주기와 프로덕션 승인

Knowledge(RAG) Backend Knowledge Backend

검색 시점에 ACL과 데이터 분류로 필터링합니다 · Agent 유형과 Manifest 명세

호출자는 URL·헤더·토큰 endpoint를 지정할 수 없습니다 · Agent 요청 처리 흐름

위임 모드 / 독립 모드 Delegated / Independent

위임 모드는 사용자를 대신해 동작하고, 독립 모드는 Agent 자체 권한으로만 동작합니다.

권한 교집합 Scope intersection

유효 권한은 사용자 권한 ∩ Agent 권한 ∩ 도구 허용 범위 ∩ 정책입니다. 위임 단계가 늘어날수록 축소만 가능합니다.

하위 Agent 호출마다 범위를 축소하고 재검증합니다 · 신뢰 경계와 보안 통제

프롬프트 인젝션 Prompt injection

검색·도구·모델 결과를 비신뢰 데이터로 처리하는 이유입니다 · 신뢰 경계와 보안 통제

실패 시 거부 fail closed

검증할 수 없으면 거부하는 원칙입니다. IdP·Credential Broker·정책 조회 실패 시 신규 자격증명을 발급하지 않습니다.

반대 개념: fail open · 신뢰 경계와 보안 통제

데이터 분류 Data classification

시크릿 / 자격증명 Secret / Credential

시크릿은 API 키·비밀번호 등 민감한 설정 값이고, 자격증명은 대상 시스템에 접근하기 위한 인증 정보입니다.

장기 시크릿은 코드·Manifest·로그에 두지 않으며, 자격증명은 Credential Broker가 단기로 발급합니다 · 신뢰 경계와 보안 통제

요청과 실행

멱등성 키 Idempotency-Key

동일 요청의 재전송이 중복 실행되지 않도록 식별하는 키입니다.

동일 키·동일 요청은 저장된 결과 반환, 동일 키·다른 요청은 409 · 로컬 환경 구성 및 호출 실습

실행 추적 컨텍스트 traceparent (W3C Trace Context)

baggage에 개인정보나 토큰을 포함하지 않습니다 · Agent 요청 처리 흐름

관측성 Observability

시스템 상태와 동작을 외부에서 파악할 수 있는 능력입니다. 실행 추적, 지표, 로그를 포함합니다.

실행 추적은 관측성의 한 요소이며, 감사(audit)는 행위 기록 목적이 다릅니다 · Agent 요청 처리 흐름

필드: type, title, status, detail, code, traceId · 로컬 환경 구성 및 호출 실습

Durable 실행 Durable execution

프로세스 재시작 이후에도 상태를 복구해 실행을 이어가는 방식입니다. 장시간 workflow에 사용합니다.

실행 엔진 제품은 TBD이며, 이 패키지는 계약만 제공합니다 · Agent 수명주기와 프로덕션 승인

HITL Human-in-the-loop

위험도가 높은 작업 전에 사람의 승인을 받는 단계입니다. 승인은 요청 digest, 정책 버전, 승인자, 만료에 결합됩니다.

단순 approved=true 플래그는 신뢰하지 않습니다 · 신뢰 경계와 보안 통제

결과 불명 상태 unknown_outcome

timeout 이후 외부 쓰기의 성공 여부를 알 수 없는 상태입니다. 자동 재실행하지 않고 대사(reconciliation)로 확인합니다.

외부 효과의 exactly-once는 보장하지 않습니다 · 신뢰 경계와 보안 통제
