ADR-035: Evaluation과 Agent Tuning

  • Status: Decided
  • Baseline: v0.1 보강 / Q35
  • Date: 2026-11-06
  • Owner / 회사 승인자: TBD
  • Source: 기준선, 근거와 참고 자료

Context

평가가 배포 전 게이트에만 있으면 운영 중 품질 저하를 발견하고 개선하는 경로가 없다.

Decision

Evaluation은 배포 전 평가·실행 추적 분석·운영 모니터링 3단계로 수행하고, 위험도 high Agent는 red teaming을 포함한다. Agent Tuning(FastTrack)은 평가 결과를 근거로 개선하며, 결과는 새 불변 버전으로 다시 평가·승인받는다. 승인 요건은 줄이지 않는다.

Alternatives considered

Tuning 결과의 즉시 반영: 승인 절차를 우회한다.

Consequences

평가 결과 스키마는 v0.1 계약을 그대로 사용한다. Tuning 자동화와 미세조정 파이프라인은 목표 규칙이다. 구현 완료 여부는 해당 계약 테스트와 통합 증거로 별도 판단해야 한다(MUST).

Constraints

회사 환경·제품·운영 수치는 TBD. 예제 값은 production 기본값이 아니다.

Related contracts / verification

Security impact

tenant·principal·Agent/workload·정책 버전을 경계에서 검증하고 최소 권한을 유지해야 한다(MUST). 감사 로그에는 토큰·secret·원문 개인정보를 기록해서는 안 된다(MUST NOT).
