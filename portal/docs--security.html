배포 전 기준

TLS·workload 인증·network policy·secret rotation·audit tamper resistance는 MUST다. 모든 tenant scoped lookup에는 tenant 조건이 포함되어야 한다. invocation ID만으로 poll/cancel/events를 허용하지 않는다. raw prompt/output 로깅은 기본 비활성화한다. 민감정보 평가·삭제·보존 절차는 회사 정책 TBD다. CORS·rate limiting·body size·timeout·egress quotas는 위험별 policy로 적용한다. 수치는 TBD. Python 예제는 합성 bearer가 고정 매핑된 로컬 mock이며 JWT 검증 제품이 아니다.
