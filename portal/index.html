Core Systems

플랫폼은 AI Platform Applications, Agent Platform APIs, Agent Factory, Agent Runtime, Agent Tools, Agent Identity, Agent Observability, Agent Evaluation, Agent Gateway, Agent Tuning의 10개 Core System으로 구성됩니다. 층 구조와 책임은 Core Systems 아키텍처를, 외부 근거는 근거와 참고 자료를 참고하십시오.
