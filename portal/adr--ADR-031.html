ADR-031: Core Systems 명칭과 경계

  • Status: Decided
  • Baseline: v0.1 보강 / Q31
  • Date: 2026-11-06
  • Owner / 회사 승인자: TBD
  • Source: 기준선, 근거와 참고 자료

Context

플랫폼 구성요소 이름이 문서마다 달라 진입 경계와 반출 경계를 혼동할 수 있다. 의도한 아키텍처는 10개 Core System이다.

Decision

플랫폼은 AI Platform Applications, Agent Platform APIs, Agent Factory, Agent Runtime, Agent Tools, Agent Identity, Agent Observability, Agent Evaluation, Agent Gateway, Agent Tuning의 10개 Core System으로 구성한다. 진입(northbound) 경계는 Agent Platform APIs, 외부 모델·도구로 나가는 반출(egress) 경계는 Agent Gateway(모델 경로·도구 경로)다. Agent Tools는 Tool Registry·도구 descriptor·adapter·도구 정책·감사를 소유하고, 도구 호출의 집행은 Agent Gateway 도구 경로가 수행한다. Knowledge(RAG) 검색은 Agent Runtime이 소비하는 하위 기능이다.

Alternatives considered

기존 명칭 유지(Agent Gateway = 진입): 의도한 Core Systems 구조와 맞지 않는다.

Consequences

ADR-009의 'Tool Gateway는 Agent Tools의 구성 요소' 규정은 소유(Registry·정책·감사)와 집행(도구 경로)으로 나눠 대체한다. ADR-012의 분리 규정은 'Agent Platform APIs(진입)와 Agent Gateway 모델 경로(반출)의 논리 분리'로 해석한다. 계약 파일명(agent-gateway.openapi.json, model-gateway.openapi.json, tool-gateway.openapi.json)과 component 식별자는 legacy alias로 유지한다. 구현 완료 여부는 해당 계약 테스트와 통합 증거로 별도 판단해야 한다(MUST).

Constraints

회사 환경·제품·운영 수치는 TBD. 예제 값은 production 기본값이 아니다.

Related contracts / verification

Security impact

tenant·principal·Agent/workload·정책 버전을 경계에서 검증하고 최소 권한을 유지해야 한다(MUST). 감사 로그에는 토큰·secret·원문 개인정보를 기록해서는 안 된다(MUST NOT).

Supersession / migration

ADR-009, ADR-012를 일부 대체한다. 계약 제목·파일명 변경은 새 released snapshot과 함께 별도 변경으로 수행한다.
