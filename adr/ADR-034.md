# ADR-034: Observability 규격

- Status: Decided
- Baseline: v0.1 보강 / Q34
- Date: 2026-11-06
- Owner / 회사 승인자: TBD
- Source: [기준선](../docs/requirements/baseline-v0.1.md), [근거와 참고 자료](../docs/onboarding/10-references.md)

## Context
구성요소마다 다른 trace 형식을 쓰면 하나의 실행으로 연결되지 않는다.

## Decision
실행 추적은 W3C Trace Context로 전파하고, span 이름과 속성은 OpenTelemetry GenAI semantic conventions를 따른다. 규격이 Development 단계이므로 사용 버전을 고정·기록한다.

## Alternatives considered
자체 trace 형식: 도구·백엔드 호환성을 잃는다.

## Consequences
v0.1은 trace context 전파만 mock에서 검증한다. span 속성 검증은 목표 규칙이다.
구현 완료 여부는 해당 계약 테스트와 통합 증거로 별도 판단해야 한다(MUST).

## Constraints
회사 환경·제품·운영 수치는 TBD. 예제 값은 production 기본값이 아니다.

## Related contracts / verification
[Observability](../docs/observability.md) · [Core Systems 구현 상태](../docs/core-systems.md#구현-상태)

## Security impact
tenant·principal·Agent/workload·정책 버전을 경계에서 검증하고 최소 권한을 유지해야 한다(MUST).
감사 로그에는 토큰·secret·원문 개인정보를 기록해서는 안 된다(MUST NOT).

## Supersession / migration
고정 버전 전환은 계약 변경 절차를 따른다. 버전 선정은 TBD-12이다.
