# ADR-036: Agent Card

- Status: Decided
- Baseline: v0.1 보강 / Q36
- Date: 2026-11-06
- Owner / 회사 승인자: TBD
- Source: [기준선](../docs/requirements/baseline-v0.1.md), [근거와 참고 자료](../docs/onboarding/10-references.md)

## Context
팀 간 Agent 발견 정보를 문서나 메신저로 공유하면 최신성과 위변조 여부를 확인할 수 없다.

## Decision
A2A 프로토콜을 채택하거나 Agent를 다른 팀·외부에 노출할 때, Registry가 Manifest와 등록 정보에서 A2A 1.0.0 Agent Card를 생성하고 조직 키로 JWS(JCS 정규화) 서명해 발행한다. production-approved 버전에만 발행하며, 사내 Agent는 공개 well-known 카드 없이 인증된 Registry 조회로만 제공한다.

## Alternatives considered
카드 수동 작성: 버전·상태와 동기화되지 않는다. 서명 생략: 위변조를 확인할 수 없다.

## Consequences
ADR-020의 'A2A는 선택' 원칙은 유지한다. 이 ADR은 발견 정보를 발행하는 경우의 형식과 규칙을 정한다. v0.1은 규칙만 정의한다(목표 규칙).
구현 완료 여부는 해당 계약 테스트와 통합 증거로 별도 판단해야 한다(MUST).

## Constraints
회사 환경·제품·운영 수치는 TBD. 예제 값은 production 기본값이 아니다.

## Security impact
tenant·principal·Agent/workload·정책 버전을 경계에서 검증하고 최소 권한을 유지해야 한다(MUST).
감사 로그에는 토큰·secret·원문 개인정보를 기록해서는 안 된다(MUST NOT).

## Supersession / migration
ADR-020을 보완한다. Registry 조회 API 확장은 새 계약 버전으로 도입한다.
