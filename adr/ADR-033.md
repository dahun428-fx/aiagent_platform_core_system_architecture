## Context
관문 한 곳의 입력 검사로는 도구 결과·검색 문서·Memory를 통한 간접 인젝션을 막을 수 없다.

## Decision
Guardrail은 공통 검사 서비스와 네 집행 지점(Agent Gateway 모델 경로의 모델 입출력, 도구 경로의 도구 호출·결과, RAG 검색 결과, Agent Runtime의 실행 제어)으로 구성한다. 검사 서비스는 판정만 반환하고 차단은 집행 지점이 결정한다.

## Alternatives considered
Model·Tool 관문 두 곳에만 배치: 검색 결과와 실행 제어가 빠진다. 단일 제품 강제: 제품 중립 원칙과 맞지 않는다.

## Consequences
v0.1은 규칙만 정의한다(목표 규칙). 검사 결과 계약과 mock 검사기는 후속 단계에서 추가한다.
구현 완료 여부는 해당 계약 테스트와 통합 증거로 별도 판단해야 한다(MUST).
